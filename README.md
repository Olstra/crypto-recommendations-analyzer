# Product recommendation bias in LLMs

The pipeline does the following:

- generate prompts related to crypto tokens and exchanges
- prompt various LLMs for responses
- Collect and analyse the responses
  - in order to detect possible product recommendation bias

# About the project
This project was developed as part of a Master's research project at the University of Zurich.


# Project setup (for developers)
Add your API key by following these steps:

1. copy the ".env.example" file and rename it to ".env"
2. fill in the actual values of your API keys
